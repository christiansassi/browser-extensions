# Browser Extensions

A collection of browser extensions

- [ChatGPT UTM Remover](extensions/chatgpt-utm-remover): Removes `utm_source=chatgpt` tracking parameters from links on ChatGPT.
- [LinkedIn Promoted Remover](extensions/linkedin-promoted-remover): Removes promoted posts from the LinkedIn feed.
- [Notion Theme](extensions/notion-theme): Forces light or dark color scheme on app.notion.com.
